# Implementation Plan: Workspace Search & Media/Tag Filtering

Add comprehensive search and multi-faceted filtering for indexed workspace materials by media type (`Documents`, `Videos`, `Web Links`) and pedagogical tags (`lecture`, `reading`, `tutorial`, etc.), with automated AI tagging and manual tag management.

## 1. Feature Architecture & User Experience

### A. Media Type Filter Controls
- Segmented filter bar above the Uploaded Materials section in `WorkspaceLibrary.tsx`:
  - **All Materials** (with count badge)
  - **Documents** (PDF, Word, Slides, Spreadsheets)
  - **Videos** (YouTube, Video uploads, Lecture streams)
  - **Web Links** (Articles, Documentation, Academic URLs)
- Seamless icon indicators and clean active state matching StudyWeb's design system.

### B. Pedagogical Tag Filter Chips (Multi-Select)
- Filter chips below the media selector:
  - High-yield pedagogical categories: `Lecture`, `Reading`, `Tutorial`, `Practice`, `Research`, `Exam Prep`.
  - Dynamic discovery of any custom tags created by users or generated by Gemini.
  - Multi-select capability: clicking tags toggles them in the active filter set.
  - "Clear filters" action button when filters are active.

### C. Full-Text Material Search
- Search bar with instant real-time matching across:
  - Material Name / Title
  - AI Academic Summary
  - Key Concepts & Highlights
  - Extracted Text & Transcription
  - Assigned Tags
- Highlight match count (e.g., "Showing 3 of 12 materials") and clear search button.

### D. Automated AI Tagging & Manual Tag Editing
- **Automated Tagging**: Enhance `studyMaterialPipeline.ts` so Gemini automatically classifies materials into pedagogical tags (`Lecture`, `Reading`, `Tutorial`, `Problem Set`, etc.) based on content structure and media type.
- **Manual Tag Editing**:
  - Add an "Edit Tags" button/modal on each card in `WorkspaceLibrary.tsx` and inside `QuickPreviewModal.tsx`.
  - Allow students to add new custom tags or remove existing tags.
  - Persist updated tags immediately to Supabase `workspace_files` and update local workspace state.

## 2. Target Files & Code Changes

1. **`src/services/studyMaterialPipeline.ts`**:
   - Update `runGeminiStructuredAnalysis` system instruction to enforce standardized pedagogical tags:
     - Videos with instructional structure $\rightarrow$ `Lecture`, `Tutorial`.
     - Documents and web articles $\rightarrow$ `Reading`, `Reference`, `Study Notes`.
     - Problem sets / questions $\rightarrow$ `Practice`, `Problem Set`.
   - Ensure default fallback tags include media format and pedagogical category.

2. **`src/components/Dashboard/WorkspaceLibrary.tsx`**:
   - Add state: `selectedMediaType`, `selectedTags`, `searchQuery`, `editingFileTags`.
   - Filter pipeline calculating `filteredFiles` with multi-facet conjunction.
   - Render Search Input + Media Type segmented control + Multi-select Tag row.
   - Render interactive tag manager dialog allowing students to type new tags and delete tags.
   - Add empty search state with clear button if no items match.

3. **`src/components/Dashboard/QuickPreviewModal.tsx`**:
   - Render interactive tags with a "+ Add Tag" button and tag deletion buttons so users can refine tags while previewing resources.
   - Call `onUpdateTags(fileId, newTags)` to propagate changes.

4. **`src/services/WorkspaceSyncService.ts`**:
   - Add/verify `updateFileTags(fileId, tags)` method to persist modified tags in Supabase `workspace_files`.
